Mobile Phone Access via GitHub Pages

Access Your Budget on Your Phone in 3 Minutes

By publishing this project via GitHub Pages, you get a secure, free HTTPS web app that works on your iPhone or Android with zero app store installs.

1

Open in Visual Studio

Open this project in VS Code or Visual Studio. Run with Live Server to test locally.

2

Push to GitHub

Create a GitHub repository, commit index.html, and enable GitHub Pages in Settings.

3

Save to Home Screen

Open the URL on your phone browser and tap "Add to Home Screen" to use as a native app icon!

How to Connect Your Google Sheet (Zero-Backend)

Google Sheets allows publishing as a live CSV feed that this app reads securely in real time.

1

Format Your Sheet Columns

In your Google Sheet, ensure row 1 has these headers: Date, Description, Category, Type, Amount, Notes.

2

Publish to the Web as CSV

Click File → Share → Publish to web. Under link settings, select your sheet tab and change format from "Web page" to Comma-separated values (.csv). Click Publish.

3

Paste Your Link & Sync

Paste your published link into the input below or click "Connect Sheet". The system will automatically fetch, clean, and visualize all transactions.

Tip: You can also paste a standard Google Sheets sharing link (e.g. https://docs.google.com/spreadsheets/d/SHEET_ID/edit) and FinTrack will auto-convert it.
